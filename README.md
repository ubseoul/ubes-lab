# Lab notebook setup (5 minutes)
1. Create a new GitHub repo (e.g. `lab-notebook`), upload everything in this folder.
2. Repo Settings → Pages → Source: Deploy from branch → `main` / root. Your site appears at `https://<you>.github.io/lab-notebook/`.
3. In ChatGPT, connect GitHub (Settings → Connectors) and give it access to this repo.
4. Paste the contents of `CHATGPT_INSTRUCTIONS.md` into a ChatGPT Project's instructions (or a custom GPT).
5. Send a photo with "new experiment" or "update <title>". Done.
